# .kiro/reports — Evidencia para la sustentación

> Carpeta de artefactos que sirven para defender la solución ante el panel.
> Cada archivo aquí es evidencia de una decisión o un resultado, no código de la app.

| Archivo | Propósito | Estado |
|---|---|---|
| `adr/` | Registros de decisiones de arquitectura (2–3 ADR obligatorios) | pendiente |

| `risks.md` | Riesgos técnicos y mitigaciones | pendiente |

| `ai-usage-declaration.md` | Declaración de uso de IA (máx media página) | pendiente |
| `panel-qa-prep.md` | Preguntas probables del panel y respuestas defendibles | pendiente |
| `coverage/` | Reporte de cobertura de pruebas | pendiente |

## Cómo se usa esta carpeta

- Los reportes se van llenando a medida que se toman decisiones y se ejecutan pruebas.
- El documento de solución final (PDF, máx 4 págs) se arma consolidando estos insumos.
- `panel-qa-prep.md` es el ensayo de la sustentación: se actualiza en cada fase.
